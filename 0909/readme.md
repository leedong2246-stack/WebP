## 9월 9일 수업내용

<!DOCTYPE html> -HTML5 문서임을알리는지시어
</html> 끝을 알리는 태그
head : 파일의 대한 정보를 적음
body : 브라우저의 내용을 보여줌
속성 값에 불필요한 공 문자, HTML5 표준에 어긋남
태그와 속성은 대소문자 구분 없음

01title_tag

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>첫 타이틀</title>
</head>
<body>
    페이지에 타이틀을 다는 예제 입니다. 
    타이틀은 브라우저의 타이틀바에 보입니다.
</body>
</html>
